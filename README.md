# 🎨 DreamCanvas – AI Text-to-Image Generator

DreamCanvas is an AI-based text-to-image generator that converts user-provided text prompts into images.

## 🎯 Objective

The objective of DreamCanvas is to provide a simple interface where users can enter a text prompt and generate an AI-created image.

## ✨ Features

- 🎨 Text-to-image generation
- 🖥️ Simple Streamlit interface
- ✨ User-friendly prompt input
- 🤖 AI-powered image generation

## 🛠️ Technologies Used

- Python
- Streamlit
- PyTorch
- Hugging Face Diffusers
- Transformers
- Pillow
